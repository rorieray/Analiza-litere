Ce litere ascunde
un articol Wikipedia?

Adaugă un link și descoperă frecvența literelor, probabilitățile lor de apariție și proporția vocalelor și a consoanelor.

Română sau engleză: limba articolului este identificată automat din informațiile Wikipedia, fără salvarea unei preferințe. Se analizează doar paragrafele, fără tabele, liste, imagini sau note de subsol. Este necesară o conexiune la internet.

Ai deja textul? Îl poți lipi aici.

Cum calculăm

De la apariții la probabilitate

fliteră = Nliteră / N

N este numărul total de litere acceptate. Nliteră este numărul de apariții ale unei litere. Probabilitatea se referă la selectarea unei poziții la întâmplare din acest text, nu la orice text în limba selectată.

Ce păstrăm din text

Vocale: . Celelalte litere, inclusiv y, sunt clasificate drept consoane. Analizăm litere scrise, nu sunete. Valorile afișate sunt rotunjite.

Pentru Wikipedia se păstrează textul vizibil al legăturilor din paragrafe, fără adresele lor. Nu sunt incluse titlurile de secțiuni, listele, tabelele, legendele imaginilor sau referințele. Rezultatele pot diferi de cele obținute prin copiere manuală.
